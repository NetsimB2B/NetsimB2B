## ERP Karmaşıklığını Gizle

Netsim tarafında yüzlerce alan bulunabilir.
B2B kullanıcısına yalnızca yaptığı iş için gerekli bilgiler gösterilmelidir.

## Kullanıcı Odaklı Terminoloji

Teknik ERP alanları doğrudan kullanıcıya gösterilmemelidir.

Örneğin:
ALISSATIS_NO yerine Sipariş No

## Minimum Click

Sık yapılan işlemler mümkün olduğunca az adımda tamamlanmalıdır.

Örneğin:
- Siparişi tekrar et
- Hızlı sipariş
- Favoriden sepete ekle

## Bilgi Önceliği

Kullanıcı açısından kritik bilgiler öncelikli gösterilmelidir.

1. Ürün
2. Fiyat
3. Stok
4. Teslimat

## Finansal Şeffaflık

Kullanıcı:
- bakiye
- vadesi geçen
- limit
- ödeme

bilgilerini kolay anlayabilmelidir.

## Sistem Durumu Görünürlüğü

Kullanıcı yaptığı işlemin hangi aşamada olduğunu anlayabilmelidir.

Örneğin:
Sipariş verildi
→ hazırlanıyor
→ kısmi sevk
→ sevk edildi

## Hata Yönetimi

## Empty States

Hiç veri olmayan ekranlarda boş tablo göstermek yerine yönlendirici mesaj kullanılmalıdır.

## Loading

Skeleton loading tercihleri açıklanmalıdır.

## Confirmation

Riskli işlemler:
- sipariş iptal
- ürün silme
- ödeme
gibi işlemlerde confirmation davranışı tanımlanmalıdır.

## Responsive UX

Mobil kullanımda temel ticari işlemler korunmalıdır.

## Accessibility

- Klavye kullanımı
- Contrast
- Focus state
- Form label
gibi standartlar belirtilebilir.
